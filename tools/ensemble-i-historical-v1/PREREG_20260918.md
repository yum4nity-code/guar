# Guardian Ensemble I — historical holdout preregistration

Date: 2026-09-18

## Purpose

Test whether several previously observed weak but directionally informative mechanisms become economically useful when combined without re-tuning their original thresholds.

This is not another AS2 execution search.

## Data split

- Warmup only: 2004-11-08 through 2005-02-28
- Historical holdout: 2005-03-01 through 2016-12-31
- 2017-2025 is already contaminated/development data and is NOT reread by this run
- 2026 remains closed
- One market pass

The 2005-2016 holdout interval has not been used by Atlas II-V, FMC, Assembly I, or AS2 Conversion/Execution Labs, whose development/test windows began in 2017 or later. A failed preflight before this revision inspected only the payload index metadata and did not decode market bars.

## Frozen vote definitions

All ensemble decisions occur only on exact UTC-hour boundaries and use completed causal M5 information.

### SKEW_REV
Source mechanism: A4_02 Realized Skew Reversal.
- prior 24 completed M5 returns
- standardized third moment
- active when abs(skew) >= 1.0
- vote opposite skew sign

### TAIL_EXH
Source mechanism: A5_03 Tail Count Exhaustion.
- prior 24 completed M5 returns
- median and robust scale 1.4826*MAD
- tails beyond median +/- 1.5 robust-scale
- at least 4 total tails
- absolute up-tail/down-tail count imbalance >= 3
- vote opposite dominant tail side

### STRETCH_MR
Source mechanism: A3_06 Mean-Revert Stretch.
- causal recursive EMA20 M5, alpha 2/21
- Wilder ATR14 M5
- active when abs((last completed M5 close - EMA20) / ATR) >= 2.0
- vote toward EMA

### SCALE_CONFLICT
Source mechanism: A2_03 Scale Conflict.
- evaluated only on the hourly subset of its original M15 schedule
- slow move = close[-4] - close[-25]
- fast move = close[-1] - close[-4]
- active when slow and fast have opposite sign
- vote with slow move

### SEASONALITY
Source mechanism: A4_06 Intraday Seasonality.
- rolling last 60 prior same-UTC-hour normalized returns
- minimum 40 observations
- normalized by current causal ATR14 M5 in the same manner as Atlas IV
- vote with rolling mean sign
- current completed hour is added only after the decision at the boundary

## Frozen ensembles

### E1_CONSENSUS_2PLUS_4
Use SKEW_REV, TAIL_EXH, STRETCH_MR, SCALE_CONFLICT.
- at least 2 votes active
- every active vote must agree
- direction = unanimous direction

### E2_DIVERSE_SCORE_5
Use all five votes.
- at least 3 votes active
- abs(sum of equal-weight votes) >= 2
- direction = sign of vote sum

### E3_AS2_CONFIRMED
Use AS2 core plus independent confirmation.
- SKEW_REV must be active
- VOV coefficient of variation over four six-return realized-variance blocks >= 0.75
- at least one of TAIL_EXH, STRETCH_MR, SCALE_CONFLICT, SEASONALITY must agree with SKEW_REV
- direction = SKEW_REV direction

No fitted weights are used.

## Execution

- entry: current M1 open at the hourly decision timestamp, identical causal timing convention to Atlas/Assembly
- 1R = 1.5 * Wilder ATR14 M5
- exit: uncapped fixed TIME_H60 only
- no TP
- no SL
- no BE
- no partial
- no trailing
- same-event control = exact opposite direction at identical timestamp

## Cost stress

Legacy Atlas convention retained for comparability:
- .10 and .20 are absolute XAUUSD price-cost stresses
- cost is subtracted before normalization by the row-specific risk

## Analysis

- H60 only
- 60-minute non-overlap per ensemble and variant
- rows crossing calendar gaps excluded
- Benjamini-Hochberg separately across the 3 absolute signal tests and the 3 signal-minus-control tests
- daily block bootstrap and daily sign-flip tests
- exact same-event matched-control delta
- concentration test after removing top 1% winners
- calendar-year results 2005-2016
- leave-one-year-out across all 12 years
- aggregate split 2005-2010 and 2011-2016

## Historical holdout strict gate

Every condition must pass:
- N >= 300
- .10 PF >= 1.10
- .10 MeanR > 0
- .20 PF >= 1.05
- .20 MeanR > 0
- at least 9/12 positive calendar years
- 2005-2010 aggregate MeanR > 0
- 2011-2016 aggregate MeanR > 0
- signal daily-block bootstrap CI95 lower > 0
- MeanR without top 1% winners > 0
- every leave-one-year-out MeanR > 0
- absolute signal BH q <= 0.10
- signal-minus-opposite-control daily delta > 0
- delta CI95 lower > 0
- delta BH q <= 0.10
- exact matched-control mean delta > 0

## Selection rule

If more than one ensemble passes the entire historical holdout gate, select exactly one for possible later 2026 final validation using:
1. highest minimum yearly .10 MeanR
2. then highest full-holdout .20 MeanR
3. then lowest .10 max drawdown
4. then deterministic family id

If zero ensembles pass, 2026 remains closed.

This historical run does not access 2017-2025 and does not access 2026.
