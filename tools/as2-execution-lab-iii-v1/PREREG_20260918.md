### Stop-only rules
- initial stop is evaluated on every M1
- if stop is not hit, exit at H60 close
- favorable excursion remains completely uncapped

### Break-even rules
- initial SL = 2.5R
- when favorable excursion reaches the frozen trigger (+1.5R or +2.0R), BE becomes active only from the next M1
- once active, first subsequent M1 touching entry exits at 0R
- no take-profit
- if no BE/SL exit occurs, exit at H60 close
- if initial SL and BE trigger both occur within the same M1 before activation, initial SL is scored first
