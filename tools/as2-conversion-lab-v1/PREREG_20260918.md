## Exact path semantics inherited from Night Atlas

For each threshold X in {0.5R, 1.0R, 1.5R, 2.0R}, `hit_X_winner` records the first side touched between +X R and -X R:
- PLUS = favorable threshold first
- MINUS = adverse threshold first
- AMBIGUOUS = both sides touched within the same M1 bar

`hit_X_minute` records the minute of that first touch.

For conversion simulation, AMBIGUOUS is scored conservatively as MINUS.

## Candidate set

No entry/filter/session changes are allowed.

Three fixed-time exits:
- TIME_H15
- TIME_H30
- TIME_H60

Twelve symmetric barrier + time-stop exits:
- +/-0.5R with H15/H30/H60
- +/-1.0R with H15/H30/H60
- +/-1.5R with H15/H30/H60
- +/-2.0R with H15/H30/H60

If the symmetric barrier is touched before the time-stop, exit at that barrier. Otherwise exit at the recorded endpoint for that horizon.

No asymmetric TP/SL, break-even, trailing, partial exits, or runner rules are simulated because the frozen path columns do not support exact reconstruction of those rules.

## Costs

Legacy Atlas cost convention is preserved:
- subtract 0.10 or 0.20 absolute XAUUSD price units divided by the row-specific 1R
- 1R = 1.5 * Wilder ATR14 M5

## Multiple testing

Fifteen conversion candidates are evaluated.

Two Benjamini-Hochberg corrections are applied across all 15 candidates:
1. signal daily-mean one-sided sign-flip tests versus zero
2. signal-minus-opposite-control daily-delta one-sided sign-flip tests

## Strict conversion gate

A candidate passes only if all are true:
- N >= 500
- .10 PF >= 1.10
- .10 MeanR > 0
- .20 PF >= 1.05
- .20 MeanR > 0
- at least 2/3 years positive at .10
- daily-block bootstrap signal CI95 lower > 0
- MeanR without top 1% winners > 0
- signal BH q <= 0.10
- signal-minus-control daily delta > 0
- delta CI95 lower > 0
- delta BH q <= 0.10
- exact same-event matched-control delta > 0

## Final-candidate selection rule

If multiple candidates pass the full strict gate, choose one automatically for the untouched 2026 final vault using this frozen ordering:
1. highest minimum yearly MeanR at .10 across 2023/2024/2025
2. highest full-sample MeanR at .20
3. lowest full-sample max drawdown at .10
4. deterministic candidate id tie-break

If zero candidates pass, 2026 is not opened.

## Path diagnostics

The lab also reports, descriptively:
- MFE/MAE ratio at H5/H15/H30/H60
- percentage MFE-before-MAE
- median / p25 / p75 minute to MFE and MAE
- PLUS/MINUS/AMBIGUOUS/NONE first-touch rates for 0.5R/1R/1.5R/2R at H15/H30/H60

These diagnostics cannot override the strict gate.
