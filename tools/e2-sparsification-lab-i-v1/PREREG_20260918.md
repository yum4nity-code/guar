# Guardian E2 Sparsification Lab I V1 — preregistration

Date: 2026-09-18

## Purpose

The frozen Ensemble I historical holdout showed that E2_DIVERSE_SCORE_5 retained a strong relative directional advantage versus the exact opposite direction, but failed absolute profitability after costs.

This lab asks one narrower question:

> Is the directional information economically usable when trades are restricted only by the strength/breadth of the already-frozen equal-weight vote?

No new market mechanism, entry feature, exit rule, component weight, session filter, or component-specific threshold is introduced.

## Frozen E2 semantics

E2_DIVERSE_SCORE_5 uses five equal-weight causal votes:
- SKEW_REV
- TAIL_EXH
- STRETCH_MR
- SCALE_CONFLICT
- SEASONALITY

Original E2 admission:
- at least 3 active votes
- absolute equal-weight vote sum >=2
- direction = sign of vote sum

For every E2 event the frozen Ensemble I signal file stores:
- `event_strength` = absolute equal-weight vote sum ("vote margin")
- `event_aux` = number of active votes

The exact opposite direction at the same timestamp is retained as the matched control.

## Frozen sparsification candidates

Seven and only seven selectors are tested:

1. `SP0_BASE_E2`
   - original E2, no extra filter

2. `SP1_MARGIN3`
   - vote margin >=3

3. `SP2_MARGIN4`
   - vote margin >=4

4. `SP3_ACTIVE4`
   - at least 4 active votes
   - original E2 margin condition otherwise unchanged

5. `SP4_ACTIVE4_MARGIN3`
   - at least 4 active votes
   - vote margin >=3

6. `SP5_UNANIMOUS`
   - every active vote agrees
   - at least 3 active votes

7. `SP6_ACTIVE5`
   - all 5 components active
   - original E2 margin condition otherwise unchanged

No component identity filter is tested.
No component weight is fitted.
No continuous strength threshold beyond the integer equal-weight margin is tested.

## Execution

Execution is unchanged:
- hourly decision
- entry at the causal current M1 open
- 1R = 1.5 * Wilder ATR14 M5
- fixed uncapped H60 endpoint
- no TP
- no SL
- no BE
- no partial
- no trailing

Rows crossing calendar gaps are excluded.

A 60-minute non-overlap rule is applied separately per candidate and variant.

## Development blocks

Each candidate must be evaluated separately over:
- historical block: 2005-2016

Calendar-year stability is evaluated across all 21 years 2005-2025.

## Multiple testing

Seven candidates are tested.

Two separate Benjamini-Hochberg corrections are applied across all seven:
1. absolute signal daily-mean one-sided sign-flip tests
2. signal-minus-opposite-control daily-delta one-sided sign-flip tests

## Selection rule

If several candidates pass every condition, select exactly one for possible later final 2026 validation using:

1. highest worst aggregate MeanR across the three frozen subperiods:
   - 2005-2016
   - 2017-2022
   - 2023-2025
2. then highest full-development .20 MeanR
3. then lowest full-development .10 max drawdown
4. then deterministic candidate id

If no candidate passes, 2026 remains closed.

This lab itself never accesses 2026.
